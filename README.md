Mathematics Through Python: Linear Algebra & Vector Calculus

📌 Project Overview

This project is part of my academic coursework for MAT2303 – Linear Algebra & Vector Calculus at Presidency University, Bengaluru, India, as a B.Tech Artificial Intelligence & Robotics Engineering student.

The project demonstrates how Python programming can be applied to solve mathematical problems, analyze linear systems, simulate probability models, visualize geometric transformations, and calculate directional derivatives.

🎯 Project Objectives

- Apply mathematical concepts using Python programming.
- Solve homogeneous systems of linear equations.
- Analyze matrix rank, null spaces, and solution spaces.
- Simulate and visualize a three-state Markov chain.
- Perform and compare 2D shear transformations.
- Calculate and compare directional derivatives.

🧩 Programs Included

Module 1: Linear Systems

1. Solve a homogeneous system and determine the dimension of its solution space.
2. Verify solutions by substituting them into the original equations.

Module 2: Markov Chains

3. Simulate a three-state Markov chain using a transition matrix.
4. Plot state probabilities over successive transitions.

Module 3: Geometric Transformations

5. Perform shear transformations along the x-axis and y-axis.
6. Compare transformed coordinates for different shear factors.

Module 4: Vector Calculus

7. Compute the directional derivative of (f(x,y)=x^2+y^2) along a user-defined direction.
8. Compare directional derivatives for three different directions.

🛠️ Technologies Used

- Python 3 — Programming language
- NumPy — Numerical computations and array operations
- SymPy — Symbolic mathematics and algebraic calculations
- Matplotlib — Data visualization and plotting

⚙️ Installation and Setup

Make sure Python 3 is installed on your computer.

Install the required libraries using:

pip install numpy sympy matplotlib

▶️ How to Run

Open a terminal in the project directory and run the desired Python program:

python program1.py

Replace "program1.py" with the actual filename of the program you want to execute.
